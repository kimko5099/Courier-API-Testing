# Courier API Testing

Manual API testing project completed using Postman to validate Courier API endpoints and identify unexpected system behavior.

## Tools Used
- Postman
- JSON
- REST API
- GitHub

## Testing Performed
- Positive testing
- Negative testing
- Boundary value testing
- API response validation
- HTTP status code validation

## Project Contents
- **Postman** – Postman collection and environment files
- **Test_Cases** – API test cases and test scenarios
- **Test_Execution** – Test execution results
- **Screenshots** – Evidence of API responses and identified issues

## Key Testing Examples
Testing included valid and invalid input values, nonexistent IDs, zero and negative values, and validation of API responses including 200, 404, and 500 status codes.

## Purpose
This project demonstrates my ability to design and execute API test cases, perform positive and negative testing, analyze API responses, and document test results.
